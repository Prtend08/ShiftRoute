# Compact result summaries

These CSV files are small, human-readable exports used to verify the manuscript
tables and primary statistical interpretation. They exclude datasets, feature
banks, checkpoints, signed URLs, full logs, and window-level output.

`cluster_aware_inference.csv` contains the complete cluster-level analysis;
`cluster_aware_primary_comparisons.csv` is its compact primary subset. The
ImageNet100 and ImageNetV2 rows marked descriptive should not be interpreted as
confirmatory significance tests.

The ODS rows in `external_raw_baselines.csv` are limited to the valid
CIFAR-10-C configuration. Full run-level artifacts should be archived as a
separate versioned release if their redistribution is permitted.
